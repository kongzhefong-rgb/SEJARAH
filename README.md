# Jelajah Patriotik – AR Padanan Perdana Menteri

Permainan AR satu stesen menggunakan kamera dan MediaPipe Hands.

## Cara bermain
1. Buka `index.html` melalui GitHub Pages atau hosting HTTPS.
2. Benarkan akses kamera.
3. Gerakkan jari telunjuk ke kad nama.
4. Cubit ibu jari + telunjuk untuk mengambil nama.
5. Gerakkan nama ke gambar yang betul.
6. Lepaskan cubitan untuk meletakkan nama.

## Struktur
- `index.html` – antara muka
- `style.css` – reka bentuk mendatar/fullscreen
- `script.js` – logik AR dan permainan
- `assets/tokoh/` – gambar tokoh

> Nota: Kamera dalam browser biasanya memerlukan HTTPS. GitHub Pages sesuai untuk tujuan ini.
